# 🏦 Bank Marketing Prediction using Machine Learning

## 📌 Project Overview

This project analyses the Bank Marketing dataset collected from a Portuguese banking institution. The objective is to predict whether a customer will subscribe to a term deposit based on customer demographics, financial information, and previous marketing campaign details.

The project includes data preprocessing, exploratory data analysis (EDA), feature engineering, machine learning model development, and performance evaluation to identify the best predictive model.

---

## 🎯 Business Problem

Banks contact customers through phone calls to promote term deposit products. Not every customer accepts the offer, which increases marketing costs and time.

The goal of this project is to build a machine learning model that helps the bank identify customers who are more likely to subscribe to a term deposit. This enables the bank to focus on potential customers, improve campaign success rates, and reduce unnecessary marketing efforts.

---

## 📂 Dataset Information

- Dataset: Bank Marketing Dataset
- Industry: Banking
- Total Records: 45,211
- Features: 16 Input Features + 1 Target Variable
- Target Column: `y` (Yes / No)

### Features

- Age
- Job
- Marital Status
- Education
- Balance
- Housing Loan
- Personal Loan
- Contact Type
- Campaign
- Previous Campaign
- Duration
- Month
- Day
- Pdays
- Previous
- Poutcome

Target:

- `y`
  - Yes = Customer subscribed to a term deposit
  - No = Customer did not subscribe
